# Student Marks Analysis Using Python

## 📌 Project Overview

Student Marks Analysis is a beginner-friendly Python project developed to practice data processing and basic statistical calculations. The program analyzes a list of student marks and calculates the total, average, highest, and lowest marks.

This project was completed as part of my internship learning tasks at Veda Technology.

## 🎯 Objectives

- Store student marks using Python lists.
- Calculate the total and average marks.
- Identify the highest and lowest marks.
- Practice loops, user input, and built-in Python functions.
- Understand basic data analysis using Python.

## ⚙️ How to Run the Project

### Option 1: Run using Google Colab

1. Open the notebook file in this repository.
2. Download `DAY1.ipynb` if needed.
3. Open [Google Colab](https://colab.research.google.com/).
4. Select **File → Upload notebook** and upload `DAY1.ipynb`.
5. Run the notebook cells in order.
6. Enter the student marks if prompted and review the calculated results.

### Option 2: Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/satya77713/Student-Marks-Analysis.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Student-Marks-Analysis
   ```

3. Install Jupyter Notebook if it is not already installed:

   ```bash
   pip install notebook
   ```

4. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `DAY1.ipynb` and run the cells.
