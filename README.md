# Student-Marks-Analysis
A Python project that analyzes student marks by calculating the total, average, highest, and lowest scores using lists and built-in Python functions.

## 📌 Features

- Accepts student marks as input
- Calculates the total marks
- Calculates the average marks
- Finds the highest mark
- Finds the lowest mark
- Displays the results in a clear format

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
Student-Marks-Analyzer/
│── DAY1.ipynb
│── README.md
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/satya77713/Student-Marks-Analysis.git
```

2. Navigate to the project folder:

```bash
cd Student-Marks-Analysis
```

3. Run the program:

```bash
python DAY1.ipynb
```
